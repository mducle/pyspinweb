# PySpinW in a JupyterLite environment

This repo deploys a JupyterLite environment with PySpinW for testing (without a GUI).
Please go to [https://mducle.github.io/pyspinweb](https://mducle.github.io/pyspinweb).

## Building

Run the `build_wheels.sh` script and then run `jupyter lite build`. 
Copy the contents of the `_output` folder to the `gh-pages` branch.
